사용 방법

설치 후에는 더 간단합니다.

Shift+Space또는Ctrl+Space
1

한/영 전환

어느 프로그램에서든 켜 둔 Shift + Space 또는 Ctrl + Space를 누르세요.

2

설정 바꾸기

체크박스를 선택하거나 해제하면 저장 버튼 없이 즉시 반영됩니다.

3

트레이에서 관리

트레이 아이콘을 두 번 클릭해 설정을 복원하거나 우클릭 메뉴의 설정 열기·프로그램 정보를 선택하세요.

4

프로그램 완전히 종료

창의 × 버튼은 숨기기입니다. 완전 종료는 트레이 메뉴의 종료를 사용하세요.

지원 환경

Windows 10/11 x64

  • 한국어 Microsoft IME가 설치된 사용자 계정
  • 관리자 권한 없이 실행하는 일반 사용자 프로그램
  • Windows ARM64와 32비트는 현재 지원하지 않음

알아두세요

무설치의 범위

  • 포터블은 설치 폴더·시작 메뉴·제거 프로그램을 만들지 않습니다.
  • 설정은 HKCU에 저장되며, 자동 실행을 켜면 현재 EXE 경로가 HKCU Run에 등록됩니다.
  • 관리자 권한 앱에는 Windows 보안 정책상 전환 입력이 전달되지 않을 수 있습니다.
  • v0.1.4의 실제 Windows 10/11 기기 HVC는 아직 미검증이며 자동 빌드·패키지 검증과는 별도입니다.

자주 묻는 질문

프로그램 창을 닫으면 종료되나요?

아니요. × 버튼을 누르면 트레이로 숨겨집니다. 완전히 종료하려면 트레이 메뉴에서 종료를 선택해 주세요.

두 단축키를 모두 끌 수 있나요?

전환 기능을 잃지 않도록 최소 하나는 항상 켜져 있어야 합니다.

키보드 입력 내용을 수집하나요?

아니요. 지정한 두 전역 단축키만 등록하며 입력 기록, 네트워크 전송, 분석 기능이 없습니다.

포터블 폴더를 지우면 설정도 지워지나요?

아니요. 먼저 자동 실행을 끄고 트레이 메뉴에서 앱을 종료한 뒤 폴더를 지우세요. HKCU 설정은 남을 수 있으므로 필요하면 직접 정리해야 합니다.

포터블도 완전히 무흔적인가요?

아니요. 설치기는 없지만 현재 사용자 설정과 선택적 자동 실행은 HKCU 레지스트리를 사용합니다. 포터블 안내문과 릴리스의 SHA256SUMS.txt를 함께 확인하세요.
